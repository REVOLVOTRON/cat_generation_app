# Котопроизводитель

Небольшое desktop-приложение на PyQt6, которое загружает изображение кота и показывает его в окне.

## Технологии
- Python, PyQt6
- requests
- QThread для фоновой загрузки

## Запуск
Установите PyQt6 и requests: pip install PyQt6 requests. Затем выполните python main.py.

Нужен доступ к интернету. Основная точка запуска — main.py; интерфейс и фоновая загрузка находятся в ui.py и worker.py.

## Статус
Демонстрационный проект.
